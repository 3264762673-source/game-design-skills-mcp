# UI provisional rules — frozen before holdout inspection

Recorded 2026-11-09. Derivation material read: Into the Breach GDC 2019 slide text and rendered slides 2/30; Papers, Please official desktop screenshot and developer phone-port article/region diagram; W3C 2.5.8; XAG 112. No third game evidence has yet been read.

Candidate layout rules: L1 Put currently decision-relevant information close to its action/object, split durable context and conditional detail; L2 On device changes recompose the task flow instead of only shrinking the canvas; L3 Declare pixel/typography scales per layer, prefer native final-size readability over an unconditional single-grid rule.

Candidate icon rules: I1 Check icon-to-function mapping and confusion within the complete icon family; pair unfamiliar/high-consequence icons with inspectable names; I2 Distinguish focus/selected/disabled/actionable using shape or mark as well as color; I3 Specify visual bounds and hit bounds separately, test actual screen/input size.

Candidate interaction rules: X1 Specify active mode, focus owner, return target and eligible actions; X2 Expose actionable consequence before commitment when tactical/management choice depends on it, provide cancellation/recovery when compatible with intended challenge; X3 Keep navigation order and action naming consistent across keyboard/controller/touch where supported.

Holdout designated now: Backpack Hero (Jaspel). Inspect official itch/Steam material only after this file exists. Static imagery cannot validate actual hitboxes, focus transitions or error rates. Preserve unverified status for those claims.
