# Godot 项目与验证

先记录实际 `godot --version`、project.godot、目标平台、渲染器、插件与导出模板版本。Godot 4 的不同小版本不能按同一 API 清单套用；升级引擎需单独评估。沿用项目目录和输入映射，不自动创建一套全局 Manager。

制作顺序：最小可运行场景→输入/状态闭环→导入资产→表现→目标平台导出。检查 Remote Scene Tree 中节点是否真实存在，用 Debugger/Profiler 区分脚本、渲染与资源问题。性能优化先保存可复现场景和基线；对象池和额外架构只在问题需要时加入。

运行前查本机 `godot --help`。可用 headless 模式做导入和脚本/场景检查，但退出码或脚本解析通过不能证明画面、声音、输入与导出平台正常。未找到 Godot 时交付代码/配置与未运行项，不声称引擎验收通过。

交付：引擎版本、入口场景、输入动作、变更文件、运行命令及实际结果。联网、3D 与编辑器插件不在本版精简包的覆盖范围。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
