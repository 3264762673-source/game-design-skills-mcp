# Godot UI 与反馈

用 Control/Container 表达布局约束，Theme 表达组件语言；界面尺度与世界像素尺度分别声明。先确认父容器是否控制布局，再改锚点、offset 或动效。图标的视觉边界与控件输入区域分别配置。

为支持键盘/手柄的页面设置初始焦点、方向邻接与返回目标。隐藏控件可能失去焦点；关闭弹层后只恢复仍有效的来源控件，否则用明确兜底项。鼠标 hover 信息需按承诺支持的输入提供可达替代。

确认、处理中、失败、选中和焦点表达不同状态。异步购买/拾取等操作先有真实结果，再展示完成状态；取消动效不能重复结算。动效关闭时仍要显示必要状态。

验收：长文本、最小目标窗口、弹层开关、选中对象删除、断开鼠标后的整条任务及快速重复确认。自动邻接和商店的手柄标签均不是通过证据。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
