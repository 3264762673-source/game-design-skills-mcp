# Godot 动画、动效与事件

按问题选择工具，不给每个对象强配整套动画系统：

| 需求 | 工具与边界 |
|---|---|
| 离散像素帧 | AnimatedSprite2D / SpriteFrames；保持逐帧身份和关键姿态 |
| 多属性时间轴 | AnimationPlayer；关键事件与玩法状态核对 |
| 动态终值、简单属性变化 | Node.create_tween；每次新建，不复用已结束 Tween |
| 复杂状态混合 | AnimationTree 驱动 AnimationPlayer 中的动画；避免同时由别处竞争播放权 |
| 物理/程序身体 | 按约束和接触生成姿态，保留独立视觉层 |

同一节点属性指定一个写入者。新 Tween 接管前终止旧 Tween；取消时显式恢复需要恢复的基准值，不把 kill 当作自动复位。使用绑定到拥有者的 Tween，并声明暂停、退出与销毁行为。容器管理布局时动视觉子节点，避免和 Container 争写位置。

攻击动作不能每帧被普通 walk/idle 分支覆盖；进入、保持、中断、退出分别检查。方法轨道可以触发玩法事件，但必须有唯一结算权威、取消清理和重复触发处理；循环动画不依赖一次性的结束信号推进关键逻辑。

特效先区分伤害实体、必要预警和装饰，再设置并发预算、寿命和减效。共享材质的参数修改可能影响多实例，按项目决定是否独立化资源。既有 Canvas 特效代码不能直接作为 Godot 实现导入。

交付：动画工具选择、事件源、状态转换、属性拥有者、取消/暂停/销毁、减效和验证结果。时长都是待调参数。本版提供方法，未随包执行 Godot 引擎实测。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
