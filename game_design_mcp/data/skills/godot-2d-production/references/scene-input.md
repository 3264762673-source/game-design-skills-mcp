# 场景、GDScript、碰撞与输入

根据对象的职责选择 CharacterBody2D、RigidBody2D 或 Area2D；不要让贴图伸缩同时改变碰撞。父节点控制模拟位移，视觉子节点承担装饰偏移。CharacterBody2D 已有 velocity；脚本应使用它，不重复声明。移动常量/导出属性的拼写和大小写必须一致。

信号只连接到确实存在的接收者；可反复进入树的节点需考虑重复连接和清理。节点退出、物品销毁、场景切换、暂停都要有明确的状态结果。库存/伤害由玩法权威结算，动画监听确认事件。

使用 InputMap 动作名。GUI 消费的输入不应再触发世界交互；离散世界输入通常放在 _unhandled_input，持续轮询 Input 时仍须检查当前输入模式，不能假定 GUI 已阻止轮询。菜单焦点动作与玩家移动动作分别命名。

验收：快速重复输入、弹层遮挡、暂停恢复、碰撞层/掩码、目标删除和状态重入。检查实际轨迹，不用截图代替输入结果。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
