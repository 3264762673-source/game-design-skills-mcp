# 像素资产接入 Godot

记录源图尺寸、显示倍率、相机变换与 UI 比例。清晰像素风可从 nearest 采样与整数显示倍率开始，但混合渲染应保留有依据的例外；分别检查静止与相机移动，不能只凭放大图判定。

独立帧或图集可交给 AnimatedSprite2D 的 SpriteFrames；逐帧时长、循环与方向名使用资产规格。美术边界、pivot、挂点、碰撞区域分别标注。角色动画从宿主的真实状态/速度取得输入，不在 Sprite 节点假设存在 velocity。

TileMapLayer 的 local_to_map 接受本地坐标；外部全局位置先经该层 to_local 转换。地块碰撞、导航、可见纹理和装饰层分别核查，不能由透明像素自动推断。采用 TileMapLayer 前确认项目版本支持，既有 TileMap 不因整理技能而强制迁移。

验收：角色/物品在实际场景、相机移动、不同窗口比例和地块接缝下的结果；只有执行过的条件才标通过。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
