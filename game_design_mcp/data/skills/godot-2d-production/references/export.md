# Godot 导出与交付

先确定实际目标平台；安装匹配当前引擎的导出模板并建立 export preset。平台 SDK、渲染器、Web 线程/浏览器限制按当前官方文档核对，不继承旧包写死的平台版本或 CI action。

先做一次最小导出，再投入完整资产。区分编辑器运行、headless 检查、导出成功与目标平台实际启动；分别记录结果。检查输入、保存位置、字体/纹理、声音、暂停恢复和退出。发布是独立动作，生成包不自动授权上传商店。

压缩方式按资产和渲染目标选择；像素边界或透明轮廓被损伤时回退设置。删除所谓孤儿资源前检查脚本动态加载与外部路径，保留可恢复版本；不把清理导入缓存当通用修复。

交付：版本、预设名、导出产物、目标运行记录和已知缺口。没有目标设备时明确尚未实机确认。


官方文档与核查范围见 [引擎来源](engine-sources.md)。
