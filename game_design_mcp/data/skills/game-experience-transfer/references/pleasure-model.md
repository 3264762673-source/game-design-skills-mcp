# 乐趣、概念诠释与共识

## 方法内的含义

本文件把作者方法变成工作定义，用于游戏设计，不宣称构成完整心理学模型。

- **乐趣**：本次希望保留或发现的吸引力。可以包含紧张、报复、羞耻、冒险和代价，不要求每一刻都愉快。
- **体验情境**：乐趣发生时的关系和过程，包括“我知道什么、能做什么、为何在意、发生了什么”。单个标签只用于检索。
- **概念**：被赋予意义的游戏对象、规则、角色或关系。
- **诠释**：概念在本次情境里代表什么、与参与者有何关系。名称、视觉、行为和规则都能传达含义，且可能互相冲突。
- **预期共识**：设计者预计参与者会采用作品所传达的含义。实际共识需要反馈支持；用户认可设计意图不等于已经验证玩家体验。
- **体验迁移**：在新载体中重建支持某种乐趣的条件，允许更换符号和实现。映射是可检验的设计假设。
- **共识偏移**：作品的预期含义与参与者的理解有差异。偏移可能破坏原目标，也可能生成新乐趣，分别记录。

## 将乐趣写成可迁移的情境

使用短句：

> 当〔关系/处境〕成立时，通过〔行动、变化或见证〕，我得到〔结果及其意义〕；吸引力来自〔具体对比、期待或兑现〕。

例如“欺弱”可以暂定为“面对明确比我弱、仍能作出反应的对手，我用很小的代价形成持续压制，感到力量差距”。这是本次诠释候选，不能把它写成所有人对“欺弱”的固定定义。

只保留会影响迁移的维度：

| 维度 | 用来确定什么 | 容易遗漏的区别 |
|---|---|---|
| 关系 | 我、对象、旁观者处于什么位置 | 击败强者、欺负弱者、旁观强者出丑不同 |
| 能动性 | 什么由我选择、导致或见证 | 自己智取与剧情替我获胜不同 |
| 价值 | 收益或损失为什么值得在意 | 数字变大未必意味着拥有更多力量 |
| 风险与代价 | 赌什么，何时支付，能否退出 | 明知风险押注与事后被突然处罚不同 |
| 知情与预期 | 玩家、角色、系统各自知道什么 | 角色自欺与玩家受骗不同 |
| 时序 | 蓄积、等待、反转、兑现怎样连接 | 立刻变强与等待后质变不同 |
| 反馈 | 哪个变化让关系与结果可被理解 | 文案说强大，规则却持续奖励逃跑，可能产生偏移 |

每个“必要条件”标记来源为用户指定、来源可观察事实或分析假设。必要条件可以被后续实验推翻。保留原条件和修订理由，避免用修改定义来抹掉失败。

## 开放的乐趣词表

下面是提问线索，不是作者已经逐项确认的分类或定义。允许复合、重命名和新增；不要求覆盖所有项。

| 标签 | 可进一步明确的不同诠释 |
|---|---|
| 欺强 | 越级压制、利用规则智取、让强者失去威风；未必等于正面对决 |
| 欺弱 | 低成本碾压、支配、对比自身成长；需要说明“弱”如何被感知 |
| 贪念 | 想再拿一点、承担可见风险继续积累、舍不得兑现；积累也可能只是安全需求 |
| 嫉妒 | 看到他者拥有自己缺少的东西，想夺取、追平或证明自己；并非所有比较都产生嫉妒 |
| 傲慢/自欺 | 自我定位高于现实，或享受被承认的优越；区分角色相信与玩家相信 |
| 其他 | 探索、掌握、照料、创造、释放等均可使用具体情境表达 |

七宗罪可以提示遗漏的欲望角度；案例的“虚伪”也可作为一个候选标签。它们不构成封闭集合，不用比例数值伪装成精确玩家模型。

## 迁移时的三个检查

1. **关系是否对应**：对方变弱后，原来的“欺强”可能变为“欺弱”。保留名称不能补回关系变化。
2. **过程是否对应**：只有奖励相同，风险、等待或能动性丢失，可能产生另一种乐趣。
3. **意义是否可达**：规则包含关系还不够；现有反馈是否足以让参与者理解它？只描述预期，效果仍待验证。

语义偏移、抽象程度和覆盖面可以作为方向性讨论；不推导“越抽象受众必然越多”的公式，也不以人口画像作为本技能的输入门槛。
