# 迁移案例

案例用于校准执行方式。原材料是已认可的设计范例，不包含实际试玩证据。本文件新增的分析与变体标为设计假设，不声称对应原作的准确机制。

## 1. 觉醒邪教徒：关系、知情和延迟

原范例的一句话体验：一个卑微、可笑的角色相信自己正在飞升，机制暂时配合这种自我认定，之后兑现代价。

原范例使用仪式、飞升层数、变形和代价等概念。迁移时先检查它们承担的作用：

| 候选条件 | 可用的目标实现 | 要检查的偏移 |
|---|---|---|
| 地位与自我认定之间有落差 | 起始能力有限，表现庄严且自信 | 仅仅弱，不一定产生自欺或荒诞感 |
| 行动让这种认定暂时可信 | 仪式积累产生真实可见收益 | 只有嘴上宣称飞升，无法支持“机制配合” |
| 成长存在后续转化 | 达到条件发生形态或规则变化 | 单纯加数字可能丢失质变 |
| 代价延迟发生 | 变形后出现损耗或可感知的限制 | 即时付费可能变成普通资源交换 |

这四项是对范例的分析性拆解，是否都必要取决于本次明确的目标，不成为所有迁移的通用清单。

### 知情变体

固定规则：每次仪式增加进度并产生收益，达到阈值后变形；变形后每回合付出生命代价。阈值和损耗仅为原型试调值。

- A：玩家一开始就知道代价，角色仍相信自己将无条件升华。可能形成知情的冒险和旁观式荒诞。
- B：玩家直到变形才知道代价。可能形成惊讶、被欺骗感，或对旧行为的重新解释。

两者只改变信息揭示时点。不能因为都含“仪式、飞升、代价”，就认定它们迁移了相同体验；也不能预先认定隐藏信息必然更好。若输入没有明确要玩家自欺还是旁观角色自欺，给出分歧与建议，必要时询问。

尚未试玩时，两版均记录为候选映射或偏移判断，实际效果 `untested`。

## 2. 防线变成连锁：保留新乐趣

用户在访谈中确认的判例：原目标是提前布防、看敌人逼近、担心防线撑不住并最终险胜；迁移后却主要产生抽牌连锁爆发的乐趣。

- 若原来的防守等待和威胁关系缺失，结构判断为 `mismatch`，不能称原迁移成功。
- 若只有分析者预测连锁会好玩，新乐趣记 `hypothesis`，实际体验保持 `untested`。
- 若用户明确报告试玩者喜欢连锁、却没有体验到守线担忧，记录相关 `human_feedback`；原体验 `not_supported`，乐趣 `positive`，新乐趣 `observed`。若反馈更复杂，使用 `mixed`。
- 保留新方向及其乐趣；建议继续原迁移、发展新方向或两者并存。用户明确换目标后另建记录，保留父 ID 和原迁移未成功的历史。

这是目标追踪规则，不是要求任何新体验都必须修回旧体验。

## 3. 跨题材迁移贪念：示范最小可执行方案

以下是技能编写时新增的虚构设计假设，并非原材料的已验证案例。

目标乐趣句：已经有一笔可以安全拿走的收益，但为了额外收益，明知风险仍想再试一次。

来源条件：已有可保收益；可主动退出；下一次有可理解的额外收益；继续会威胁已有收益。

目标载体：回合制寻宝小玩法。以下均为初始试调规则：

1. 每局开始获得 1 枚临时宝石，警戒为 1。
2. 选择撤离：把全部临时宝石计入本局收益，结束本局。
3. 选择继续：先按当前警戒掷一次公开的六面骰。点数不高于警戒则临时宝石清零、本局收益为 0，立即结束本局；本次探索不发宝石。
4. 探索成功：获得 1 枚临时宝石，警戒增加 1，再进行下一次选择。
5. 警戒达到 5 后只能撤离，不再掷骰。新一局重新按第 1 步初始化，不带入上局警戒或临时宝石。

初始规则给出完整状态变化，但不声称数值平衡或已好玩。公开风险用于承载“明知风险仍贪”，若隐藏风险，需要重新检查是否变成探索未知或随机惊喜。

对应诊断：

- 如果失败不损失任何已得收益，原来的冒险贪念条件缺失；可能只剩免费累积。
- 如果退出由系统随机决定，主动冒险条件缺失。
- 如果继续的期望收益和实际体验使选择毫无悬念，需调整决策条件；不能因为形式上有退出按钮就宣布有乐趣。

后续小实验：仅改变“失败会不会失去临时收益”，比较参与者如何描述继续的理由，并观察何时犹豫、退出。没有实际反馈时，只交付假设与记录。
