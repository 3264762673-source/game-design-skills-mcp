# 像素场景美术：条件规则卡

研究日期：2026-11-09。预期变化是待检查的预测；来源与状态限定每条规则的使用范围。执行方案由本项目综合提出，不代表所有参考作品使用了同一实现。

依据见 [来源与案例](evidence.md)。先读触发条件与例外，再采用最小可撤回修改。

## S1 让边界表达玩法含义，不让每条材质缝都像墙

- **触发条件：**玩家把装饰当平台、看不出坑或阻挡，或地面全被高对比边线切碎。
- **候选解释：**材质、层差、危险、阻挡共用了相同边缘语法；也可能是美术与真实碰撞不一致。
- **检查方法：**先从设计/引擎取得可走、阻挡、危险示意；与实际画面叠对。没有碰撞数据时只记疑点，不能由画面宣布正确路线。
- **可执行修改：**灰盒标语义→给阻挡/危险/层差分别定线索→普通材质变化保持较弱→放入人物和任务目标→在行动决策位置检查局部边界→再加纹理。
- **不适用情况：**有意误导/隐藏的区域，需有对应的揭示设计；没有行走任务的纯背景插画也不需要统一可走规则。
- **预期变化：**画面里的空间判断更接近真实行动可能性。
- **验证与撤回：**在最容易误判的地点做路线预测与实际操作对照；若边线新增了错误阻挡暗示，撤回该装饰线索。不要用主观「立体感」替代路径正确性。
- **来源与状态：**S07/S08/S09 推导；S12 道路/农场推翻了所有行走边缘必须强边线的过宽表述。`narrowed`。

## S2 用重复组织空间，用差异服务定位

- **触发条件：**地图像复制贴图、纹理争抢注意、或玩家经过不同区域却没有可记住的结构差异。
- **候选解释：**独特装饰被重复太多；地标与普通填充无职责区别；也可能是关卡本身同构。
- **检查方法：**先检查边角和邻接，再看一整屏及连续空间；标出任务路线、稳定重复和真正需要记忆的位置。
- **可执行修改：**最小模块集铺成连续区域→修缝与不自然重影→只在暴露重复处加变体→把独特轮廓、尺度或构图集中到必要地标→重新放入角色检查。不要随机撒变体来替代空间结构。
- **不适用情况：**农田/工业设施等规律排列本来就是主题；高密度市场等也可以是目标。只有重复妨碍目标或暴露不希望的机械感时才修改。
- **预期变化：**模块复用保留生产效率，同时关键位置有可解释的差别。
- **验证与撤回：**检查前后连续截图和指定路线；若新增变体让边界更乱或地标失焦，撤回变体，重审结构。导航改善需要实际任务验证。
- **来源与状态：**S05 工艺；S08/S09 推导；S12 农田、围栏与夜市检验。`case-supported`，非已测导航改善。

## S3 把可见体积、接地点、遮挡和碰撞分别交付

- **触发条件：**角色像漂浮、走到树旁被意外挡住、前后覆盖反转，或漂亮大物件进入地图后失去空间关系。
- **候选解释：**精灵画布与接地点混用；投影不同；排序依据和碰撞依据被混为一谈。
- **检查方法：**索取真实碰撞/排序规则；对角色脚点、树干基座、房屋门口做标注，观察接近与经过时谁遮住谁。静态画面只能预审。
- **可执行修改：**给资产标原点、接地占地与视觉外伸→定共享投影→把需独立调整的阴影分离→画至少一处角色前/后经过示意→交引擎检查并记录例外。
- **不适用情况：**悬浮物、平面徽记、刻意不可能空间可设独立规则；无需为所有资产强加阴影。
- **预期变化：**空间表现与交互规格可核对，外观范围不再自动决定阻挡范围。
- **验证与撤回：**在一条经过大物件的真实路径中测试遮挡与碰撞；错误时分别修排序/碰撞/资产，不同时全改。导致视觉不连续的阴影拆分应撤回或换层级方案。
- **来源与状态：**S05 工艺；S08/S09/S12 仅视觉空间关系相容。`provisional`，本次未检查引擎行为。
