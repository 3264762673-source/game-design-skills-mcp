## 3. 比较与验收

- A：基线；B：修改版。记录顺序；多位试玩者交替 AB／BA，减轻学习和新鲜感干扰。
- 复现条件：场景、随机种子（若有）、目标密度、设备、音量与显示设置；相同回放测技术一致性，真人操作测体验。
- 行为主指标：选择一个与症状直接相关的指标，如误判率、重复无效输入或成功原因复述正确率。写清分母。
- 体验问题：分别问可控、清晰、目标感受及是否喜欢；可用固定 1–7 分记录，但这是自定义评分，不是经验证心理量表。
- 代价：关键威胁遮挡、误导性反馈、不适、帧耗时及超预算频率。
- 决策阈值：测试前按项目基线定最低有用改善和可接受代价，不能测试后为了通过临时更改。
- 适用情境：至少覆盖症状场景及会暴露副作用的场景；涉及减效、取消、暂停或重开时验证对应路径。

## 填写示例：重击看不出接触点

以下全是演示假设，没有实测结果。

- 证据假设：命中日志正确，但屏幕中心闪光盖住受击敌人；玩家不能指出受击对象。
- 采用 F02／F05：保留挥动轨迹，将命中确认定位到日志中的目标；本轮关闭中心装饰闪光，其他玩法与声音不变。
- 预期：目标复述准确率提高；同时观察重击力量感是否下降。
- 验证：孤立敌人及拥挤场景分别比较，记录回答与实际目标的一致性、力量感评价、漏看威胁。
- 回退：识别或舒适度变差，恢复配置；若仅力量感下降，下一轮单独试接触形变，不立即叠回全部闪光。
