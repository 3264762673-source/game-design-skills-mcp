# 情绪、成就与表达决策卡

这些卡把来源中的观点转成项目实验，不是已证明的“爽感公式”。来源 ID 及阅读范围见 [sources.md](sources.md)。感官刺激、操作胜任、继续欲望和主观愉悦分别记录。

## E01：让关键事件有可理解的前后变化

- **触发条件**：整局都很热闹，却说不出高潮；击败首领与普通击杀感觉接近。
- **候选解释**：缺少可感知的威胁解除或状态变化；庆祝发生在玩家仍需躲避时；平时就耗尽了表现强度。
- **检查方法**：沿一段实际游玩标记目标、威胁、玩家应对、结果和下一步。让玩家指出最紧张／最满足的位置及原因，对照真实状态；不预设每场战斗必须同一种曲线。
- **可执行修改**：挑一个关键事件，明确它改变了什么，并让变化在画面、声音或行动机会中可见。先调整表现对比或结算时机；若需调整波次、敌人或奖励，明确那是玩法改动并确认属于任务范围。胜利后保留结果辨识和继续操作的空间。
- **不适用情况**：持续压迫、冥想、无高潮探索本来就是目标；不强加爆发—收割结构。
- **预期变化**：玩家更能指出峰值及其原因，关键成功比普通事件更有意义，后续行动不受庆祝遮挡。
- **验证与撤回**：比较同一遭遇的原版和修改版，记录关键事件复述与感受。若只是降低难度、延长等待或插入动画，尚不能证明节奏改善；撤回妨碍行动的部分。
- **来源与状态**：S02 的事件生成情绪与情境意义为作者设计论述；对比与状态时间轴是本 Skill 的工程假设，待测。

## E02：玩家能把成功归因于自己的进步

- **触发条件**：奖励很密，玩家仍说“只是自动变强”“随便按都一样”，或失败后不知道如何改进。
- **候选解释**：成功信号不区分表现；成长只表现为数字；挑战与已学技能脱节；结果主要依靠运气。
- **检查方法**：问“刚才为什么成功，下次怎么重复？”对照行为、判定与奖励。区分操作熟练、策略选择和数值成长，自动战斗也可能把掌握感放在构筑而非按键上。
- **可执行修改**：选择一个已有、可重复的成功条件，给准确且分级的结果说明；将关键决策及后果放在邻近时机展示。需要练习时提供可重试的短目标和具体失败信息。不要伪造技巧奖励或为了显得玩家强大暗改判定。
- **不适用情况**：目标是放松或观看且用户不追求技能掌握；不强加精确操作考核。
- **预期变化**：玩家能够复述成功原因并再次做到，胜任感增强；不预设游玩时间一定增长。
- **验证与撤回**：保留难度基线，对比重复成功、归因说明与自报胜任感。若反馈像评分压力、掩盖结果或鼓励错误操作，则调整条件或撤回。
- **来源与状态**：P01 提供需要满足框架，P03 支持特定实验中的成功依赖反馈与胜任路径；具体教学／成长方案为待测推导。论文不保证其对享受或游玩时间有直接提升。

## E03：把选择做成玩家能理解的取舍

- **触发条件**：升级界面选项很多，玩家仍随便点，或感觉一直照提示走。
- **候选解释**：结果看不懂、差异太小；存在压倒性最优项；暂时缺乏理解信息，也可能是操作负担过高。
- **检查方法**：请玩家在选择前预测两个选项的后果，选择后描述实际差别。先查语义、信息出现时机和已有知识，再判断机制是否真的没有取舍。
- **可执行修改**：先把一个关键代价或行为变化用可比较的表达呈现；必要时给短预览或练习机会。若机制本身单一且允许改玩法，再试两个不同情境下有用的路径，保留玩家拒绝建议的空间。不要以增加按钮数替代自主性。
- **不适用情况**：初次教学需要暂时聚焦一个操作；或固定流程是明确体验目标。先验证该约束是否阻碍目标，不机械添加分支。
- **预期变化**：玩家能说明选择依据，使用情境出现差异，而非只记住推荐颜色。
- **验证与撤回**：观察预测是否准确、选择是否可执行、解释是否来自真实差异。选择变慢且理解无改善时减少无关信息；若某路径失去用途，回到机制检查。
- **来源与状态**：P01 的自主与胜任框架、S06 的理解与核心挑战方法；具体界面和选项设计为工程推导，待测。

## E04：区分“还想继续”和“刚才很喜欢”

- **触发条件**：重试、时长或领奖次数增加，但玩家评价没有改善，或反馈疲劳、空洞。
- **候选解释**：目标未完成、损失挽回、习惯或外部奖励驱动继续；也可能享受但不愿继续。行为本身不能区分这些原因。
- **检查方法**：在自然停顿处分别询问刚才的满意度、疲劳和继续意愿，再观察自愿选择。用开放问题了解原因，不从行为推断神经递质或成瘾。
- **可执行修改**：定位奖励是否帮助完成核心动作或理解进步。先试缩短重复领奖、让结算准确呈现所得、减少打断；如需改变经济或奖励频率，列为单独玩法实验。提供清楚的完成节点，不把延迟退出当作愉悦提升。
- **不适用情况**：没有体验下降证据，仅想从普通统计推断心理机制；本卡不能诊断任何人或证明特定神经机制。
- **预期变化**：满意度与核心活动体验改善，疲劳不过度增加；时长可升可降。
- **验证与撤回**：把主观满意、疲劳和行为并列；若只有重复行为增长，不得结论为更爽。满意下降或核心节奏被破坏时回退，并记录原因。
- **来源与状态**：P04 支持 wanting／liking 的概念区分，但并非游戏特效实验；P03 显示体验与自愿时长指标不可互换。工作单测量法是工程推导，待测。

## E05：为自愿表达保留可恢复的探索空间

- **触发条件**：创造、装扮或叙事玩法中，玩家只复制标准答案，所有尝试都被即时评分或惩罚截断。
- **候选解释**：没有个人赋义的机会；结果不可恢复；提示过密。也可能是目标或工具难懂，应先排除可用性问题。
- **检查方法**：观察没有任务指令时玩家是否自发尝试；请其解释物品、角色或布置对自己的意义。只接受玩家自己的解释，不替其解释“潜意识”。
- **可执行修改**：在符合项目目标的局部空间试验可撤销的组合、装扮或摆放；提供稳定规则及可返回的初始状态，减少不必要即时排名，保留可选提示与退出路径。
- **不适用情况**：精确竞赛、严格解题或固定叙事节奏是核心目标，且没有表达需求；不把自由沙盒变成所有游戏的必选项。
- **预期变化**：出现更多自发尝试及个人解释，玩家仍知道如何返回主目标。这是设计预测，不是精神分析保证。
- **验证与撤回**：比较尝试类型、个人解释和迷失情况。若只是无目的停留或目标感下降，恢复引导、缩小空间或撤回；不能仅用停留时长声称效果成立。
- **来源与状态**：S07 是精神分析理论和临床论述，只提供解释性启发；可撤销工具、玩法实验及指标是本 Skill 的原创工程假设，未有直接游戏因果证据。
