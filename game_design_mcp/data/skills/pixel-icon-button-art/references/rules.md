# 像素图标与小按钮：条件规则卡

研究日期：2026-11-09。预期变化是待检查的预测；来源与状态限定每条规则的使用范围。执行方案由本项目综合提出，不代表所有参考作品使用了同一实现。

依据见 [来源与案例](evidence.md)。先读触发条件与例外，再采用最小可撤回修改。

## I1 — 测试功能含义和同组混淆，而不只测试“像什么”

1. **触发条件**：画得像物体，玩家仍不知道按下会做什么；或多个技能/状态图标彼此混淆。
2. **候选解释**：形状分辨不足、图与功能的关系太远、名称不熟悉；三者需要分别检查。
3. **检查方法**：在完整同组图标中做“功能→选择”和“图标→解释”两种任务；分首次见到和学习后记录；分别比较纯图、图加名称，不把个人审美评分当辨识率。
4. **可执行修改**：优先改变决定功能差异的轮廓/内部标记；陌生、高后果命令保留文字或焦点/悬停/触控可打开的说明。物品图可保留世界内形象，但复杂效果用说明承载。
5. **不适用情况**：已学习且高频使用的通用操作不一定需要常驻长标签；依靠物品占格形状的玩法不能统一裁成相同方形。
6. **预期变化**：降低同组误认和首次误用；熟练用户可能需要更紧凑呈现。
7. **验证与撤回**：用未参与设计的人测试；按错误对记录混淆矩阵。若去细节损失类别区分，恢复识别特征；若标签遮挡任务区，改为可按需读取而非删除说明。
8. **来源与状态**：[S08](https://link.springer.com/content/pdf/10.3758/BRM.41.2.325.pdf) 的图标学习研究可迁移，A/B/C 是案例支持；**论文不是像素游戏实验，图标越简单越好不获支持**。

## I2 — 状态变化应传达状态名，不能只做装饰变色

1. **触发条件**：玩家分不清悬停、键盘焦点、选中、禁用、冷却或目标预览。
2. **候选解释**：状态混用同一高亮、只靠色相、缺少禁用原因，或者输入状态实现错误。
3. **检查方法**：做逐状态接触表；写每个视觉状态实际代表的系统状态。黑白/色觉模拟只能作为筛查，还需在实际背景和尺寸上检查。
4. **可执行修改**：为焦点配置清楚轮廓，为选中添加持续标记，为禁用/冷却提供原因或进度；颜色之外增加可辨的形状、文字或明暗关系。图标含义与当前状态分别编码。
5. **不适用情况**：没有某状态的控件不必造出全套状态；无信息含义的装饰色不必添加文字。
6. **预期变化**：能说明“哪里有焦点、什么已选、为何不能按”；不承诺改善战斗胜率。
7. **验证与撤回**：从鼠标移入切到手柄，再打开/关闭模态层；检查有无双焦点或丢焦点。若边框遮住小图特征，移到容器边界；若变暗文字不可读，恢复文字对比并另加禁用标识。
8. **来源与状态**：[S06](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)、[S07](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112) 支持验收原则；A/C 只支持局部视觉做法。**完整状态及其行为待测**。

## I3 — 把小像素图与交互命中区分别交付

1. **触发条件**：按钮图很清楚却常误触、点击无响应，尤其在掌机/手机或密集工具栏。
2. **候选解释**：命中区太小/重叠、输入穿透、控件禁用，或系统实际没有收到输入。
3. **检查方法**：打开 hitbox 调试层并记录 pointer-down、目标解析及结果；检查实际逻辑尺寸、间距、层级和边缘点击，而非只量源 sprite。
4. **可执行修改**：给 sprite 增加容器内边距并明确 hit bounds；密集处增大间距或重排；相邻目标避免不明确重叠；另给键盘/手柄可达路径。素材清单同时交付 visualBounds 和 hitBounds。
5. **不适用情况**：点选网格坐标本身是玩法时，不能任意膨胀至覆盖邻格；可提供缩放或辅助选择。WCAG 2.5.8 还有间距、等效入口等例外。
6. **预期变化**：降低点到邻项和重复无效点击。
7. **验证与撤回**：对目标边缘、相邻目标和弹窗遮罩逐一输入；若扩大命中区造成邻项抢点，撤回扩大并调整布局。源像素和 CSS px 的数值不得直接相等。
8. **来源与状态**：[S05](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：Web 指针目标 24×24 CSS px 为带例外的最低标准；不是所有游戏审美阈值，也不是足够舒适的普适尺寸。**工程要求，三个游戏均未测 hitbox**。
