# 来源与跨作品检验

研究基线：2026-11-09；整理：2026-11-20。没有新增玩家实验，未提升原有证据等级。规则编号仅在所属主题内有效。

## 人物造型

| 规则 | 检查结果 |
|---|---|
| C1 占屏尺寸和身份 | **保留，收窄目标。**多人图通过发型、帽子、衣色等区别小人物，但背景有更亮更饱和区域。只要求在具体任务里能找到/区分需要区分的主体，不要求主角全屏最亮，也不把「1–2 锚点」变成硬数字。 |
| C2 恒定身份/变化通道 | **暂缓强结论。**多人图是不同人物的一张状态，不是同一人物状态序列；能检查局部身份差异，无法检验状态转换。规则保留为制作检查，状态为 provisional。 |
| C3 投影/方向 | **局部相容，完整验证不足。**道路、夜市等静态图包含不同朝向的人物与共同地面体系；没有完整转向帧，不能确认镜像、手性或灯光处理。 |

## 场景地块

| 规则 | 检查结果 |
|---|---|
| S1 统一显著行走边缘 | **收窄。**道路图的草/土过渡没有统一高对比边线；农场也是开放连续地面。撤销「所有可行走边缘都要显著边线」要求，改为优先编码阻挡、危险、层差及需要作决定的位置。材质接缝不能一律暗示碰撞。 |
| S2 模块/地标 | **保留并限定。**农田行列、围栏、建筑与单独地物相容；夜市说明高密度装饰也可能是目标。规则关注重复是否妨碍任务或暴露不希望的拼贴，不禁止密集布置。 |
| S3 投影/接地/遮挡 | **视觉部分相容。**人物脚点、房屋基座、树干和前后覆盖形成空间关系；碰撞和遮挡时的可操作性仍未验证，不能据图给碰撞尺寸。 |

## 物品造型

| 规则 | 检查结果 |
|---|---|
| I1 类别/形状 | **保留并限定粒度。**多人图菜叶、瓜形、工具和箱体能观察到形状差别；不能保证所有相邻作物种类仅凭剪影可分。粗类别先区别，精确种类允许名称等辅助信息。 |
| I2 世界尺度/投影 | **保留，增加例外。**图中举起的菜叶和左下物品名称提示可见；世界物与获取提示承担不同任务，允许不同展示大小。不能把真实物理比例当硬规范。 |
| I3 交互身份 | **收窄。**农场中的作物、箱子没有统一发光外圈；漂亮单帧也无法确定全部可交互对象。改为只对本任务中必要且容易误判的对象增加线索，其他对象允许通过约定、靠近反馈和操作学习确认。 |
