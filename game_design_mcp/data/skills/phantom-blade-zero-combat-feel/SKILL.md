# 影之刃零：画面与打击手感

默认目标：玩家读懂强敌、把握时机夺回主动权，亲手接出利落而有抵抗的功夫交锋。它是基于来源的体验诠释，尚非玩家实测结论。

## 按任务读取

- 首次分析或需要解释“为什么有这种体验”：读 [体验拆解](references/deconstruction.md)。
- 需要论文依据或事实核查：读 [研究来源与决策](references/research.md)。
- 需要实机解析、高赞视频或逐帧研究：读 [视频索引与取证](references/videos.md)。索引不等于已观看；按其中阅读状态引用。
- 需要输出可实施规格：读 [动作、画面、音频规格](references/specification.md)。

用户只要 skill/研究时不制作网页。用户后续要求实现时沿用项目技术栈；默认先验证小场景交锋，是否 2D/2.5D/3D 依目标和资产确定。技能可独立使用；有体验论技能时可用它补充通用迁移判断。

## 操作流程

1. 固定参考版本、核心体验和证据范围。2023 宣传、2024/2025 试玩、后期官方介绍不能混作同一版本。每条陈述标为官方描述、实机观察、研究结论、评论者观点或设计假设。
2. 对每个动作定义玩家意图、敌人抵抗和结果：挥空、被格挡、伤害命中、成功反制、失衡、终结各有独立反馈。只有规则确认事件才触发相应命中表现。
3. 先验收动作起势、接触关系、受击反应和衔接，再加刀光、粒子、音效及镜头。逐项说明它服务“锋利/重量/连贯/掌控/释放”中的哪种含义。
4. 输出动作时序与状态转换、反馈事件表、视觉层级、音效层次、统一时间策略和性能预算。数值仅作为试调种子，不能包装成原作逆向结果。
5. 给出能推翻解释的对照实验和偏移判断。未操控、未测量、未取得录像时保留未知；交付规格不等于完成体验复刻。

## 必须保留的体验关系

- 敌人是参与交锋的对手：有准备、抵抗、失衡和恢复。不能只靠血量显示承受打击。
- 玩家掌握选择点：选进攻、继续、收手、防御或换位；精美接招不能掩盖长时间不可控。
- 普通接触和关键成功有层次：先建立压迫，再通过反制和破防释放。连续小击保持节奏，重要事件才占据主要注意力。
- 武器通过攻击轨迹、身体发力、接触声音和反作用建立身份。刀具的锋利感允许快速穿切与短促阻力；长停顿不是所有攻击的目标。
- 深色氛围仍须可读：对手姿态、兵器路径、接触点和下一次威胁始终可辨；减效时保留信息。

这些是本技能的迁移假设，按实际反馈调整。不能仅因画面类似或加了停帧就宣布成功。

## 交付标准

交付体验目标、来源清单和阅读状态、关键动作及反馈规格、候选参数、验证计划、尚未支持的结论。实际实现后再记录运行条件、录屏、事件日志和试玩结果。

研究中出现冲突时保留版本和竞争解释。例如不同年代的动作制作介绍可代表制作流程变化；缺少开发资料时不能归结成“全部手工”或“全部动捕”。
