# 动作、画面、镜头与声音规格

以下全部是面向后续原型的**工程推导与试调方案**，不是影之刃零逆向参数。当前未做 Demo、未做真人或性能测试。来源动机见 research.md；语义目标见 deconstruction.md。

## 1. 先做接触关系

每个动作描述五个阶段：准备姿态 → 发力和位移 → 有效接触 → 结果反应 → 回收/接续。阶段可以极短，但语义应可辨。

| 动作组成 | 要表达什么 | 制作要求 | 常见偏移 |
|---|---|---|---|
| 足部与重心 | 身体有支撑，力量有来源 | 位移与脚步对应；转身时有支点 | 模型滑行，刀像独立旋转道具 |
| 躯干与肩臂 | 力从身体传到武器 | 发力方向、扭转和武器轨迹对应 | 只有手臂摆动，缺少整体力度 |
| 武器轨迹 | 有刃、有方向、有作用范围 | 轨迹连续；判定位置与可见兵器对齐 | 特效扫到却没击中，或隔空受击 |
| 目标反应 | 力确实作用到对象 | 接触方向决定姿态偏转；防御与肉身受击不同 | 每刀同一闪白动作，像打 UI |
| 回收与接续 | 可以继续控制这具身体 | 下一动作起始姿态承接当前姿态；取消窗口明确 | 连招瞬移或强制长演出 |

锋利、重量、速度并非同一指标。轻刀可用短接触强调、快速贯穿、方向性后仰；重刀可用更明显准备与较长反作用。先比较动作，再调震屏。

## 2. 事件契约

实现字段为本技能定义，替换为项目同义事件即可：

```text
InputAccepted → ActionStarted → ContactResolved
ContactResolved.result = miss | blocked | damage | parried
damage / parried → 可选 Staggered → 可选 Defeated
ActionEnded / ActionCancelled → 清理动作表现
```

事件至少携带 eventId、attackId、attackerId、targetId、contactPosition、direction、surface、result、intensity、simulationTime。每个接触结算一次；一次横扫多个目标允许多个目标事件，但镜头/混音在全局汇总，避免叠加爆炸。

挥空只播挥动；被挡只播兵器碰撞与格挡反应；damage 才播伤害接触。命中不等于硬直，硬直不等于击杀。霸体对象可局部响应但不强制中断其动作，必须让玩家看清其仍有威胁。

## 3. 六类反馈矩阵

| 结果 | 动作与位置 | 画面 | 声音 | 镜头/停顿 |
|---|---|---|---|---|
| 挥空 | 保留动量和回收 | 短刀路，无命中火花 | 切风 | 通常无命中震动 |
| 被格挡 | 接触处反弹或偏转 | 小而集中的硬质火花 | 金属起音+短共鸣 | 小幅方向性冲量；保留连续性 |
| 普通伤害 | 与切入方向一致的目标反应 | 接触点短亮，刀光迅速衰减 | 切入瞬态+材质层 | 轻量强调，不能每击都打断节奏 |
| 成功反制 | 对方攻击被偏离，玩家姿态稳定 | 短而清晰的成功标记 | 清脆且不同于普通格挡 | 短暂聚焦，立即交还控制 |
| 失衡 | 防御结构打开、恢复明确 | 可读轮廓或局部状态标记 | 破裂/失稳提示 | 允许更强强调，但仍能看清机会 |
| 终结 | 对手进入终止状态 | 最强局部效果后快速回落 | 主冲击+收束尾音 | 可较强，结束后恢复基准镜头 |

“反制”由玩家输入/规则判定，不以视觉相似自行判成功。若项目不具备某类规则，不添加伪成功反馈。

## 4. 画面方向：危险环境里的清楚交锋

原作的黑暗与 Kungfupunk 意图有 O1 支持；下列颜色、分层和材质规则是本项目设计，不是原作色值测量。

- 背景使用低饱和、大体块、有限高频细节；角色轮廓与武器有足够明度分离。黑暗靠环境关系和材质营造，不能靠压黑主要动作。
- 刀光沿真实兵器路径生成，前缘明确、后缘衰减；区分“挥过的轨迹”与“实际接触”。减少整片不透明光幕。
- 接触特效集中在碰撞位置。金属以短硬火花表达，石木以碎屑表达，软材质以形变/局部切入表达；装饰不能替代目标动作。
- 烟尘、布料和环境扰动作为动作后的余波，不抢在刀锋接触前制造命中错觉。
- 危险提示同时用形态、姿态或节奏编码；具体配色依项目确定，不能未经版本核查照抄“原作某颜色必对应某招”。
- 稀有事件拥有更强亮度与更长余韵；常态保留视觉空间，避免所有攻击同时到顶。

看静帧验收轮廓与接触点；看原速连续片段验收节奏；静帧漂亮不能替代连续可读。

## 5. 镜头与时间

镜头首先同时容纳玩家、目标及下一次威胁；冲量与攻击方向相关，快速衰减回基准。连续小击合并成有限的强调，破防/终结可覆盖低优先级冲量。避免改变视角到玩家无法判断距离。

**停帧必须先选时间语义：**

- 表现冻结：权威模拟继续，只暂缓相关骨骼或效果；冻结短到不会使可见身体与碰撞体明显分离。若分离不可控，缩短或改为动作曲线强调。
- 共享战斗停顿：相关模拟、动画、冷却和敌方时间同步暂停；输入继续采样并缓存。这会改变实际节奏，属于玩法变更，不能在“只改表现”范围内偷偷采用。

两种模式都不采用阻塞 sleep。明确输入缓存采用真实时钟还是战斗时钟、暂停时是否延长；全局管理并设叠加上限。恢复后不重复结算命中，不丢输入或遗留摄像机偏移。

## 6. 声音是接触材质的一部分

一次攻击可包含准备声、挥动声、接触瞬态、材质共鸣、角色反应、环境尾音。只由对应事件触发，挥空不播切肉或撞击确认。

普通格挡以硬质金属对抗为核心，伤害命中强调切入和对象材质，反制增加独特辨识，失衡给出短促状态变化，终结才使用明显收束。变化素材保持相同语义，避免随机到像另一种武器。

用混音优先级保留当前主接触和来招提示；高密度下限制同类并发。短暂压低背景可用于重要事件，但不默认每刀压混音。静音仍可理解主要结果，减效仍保留来招信息。

## 7. 试调种子

仅供后续起步，所有数值均未测，不能称为原作参数。先用原型比较，再决定是否保留。

| 参数 | 候选起点 | 解释及检查 |
|---|---|---|
| 轻击接触表现停顿 | 0–30 ms | 与不暂停比较锋利/连续性；0 是合法选择 |
| 重要接触表现停顿 | 35–65 ms | 比较辨识收益与迟钝感；不叠加无限延长 |
| 输入缓存 | 80–120 ms | 合法动作开始时消费；不自动触发很久以前的意图 |
| 普通刀路可见尾迹 | 50–100 ms | 重复攻击不能积成不透明墙 |
| 重要接触镜头回落 | 80–160 ms | 下一次威胁到来前恢复可读 |
| 普通/重要镜头位移 | 视口高度 0–0.25% / 0.25–0.6% | 仅为起点；减效模式可为 0 |

时长用毫秒描述，不能假设所有设备固定 60 帧。动作前摇、有效段、后摇和反制窗口应按规则另调，不由这张表现表决定。

## 8. 将来实现时的验收

本轮无需执行。用户要求制作时再落实：

- 功能：挥空/被挡/伤害/反制/失衡/终结事件不混；一次接触不重复结算；取消、暂停、重开和销毁清理声音与粒子。
- 时序：记录输入接收、动作开始、碰撞结算、画面与声音提交时间。软件提交时间不能冒充屏幕到眼睛的总延迟。
- 性能：按目标设备记录帧耗时分布和峰值；60 fps 目标的单帧预算约 16.7 ms 只是工程预算，不是体验保证。优先减少装饰、后处理和粒子并发。
- 对照：同样规则与输入，仅开关受击方向、停帧、声音一致性或镜头其中一项。改变整组时明确是组合测试。
- 真人：分别问“打中了什么”“为什么这次成功”“下一步能做什么”，再问锋利、重量、连续性、掌控和不适。避免只问“爽不爽”。

体验复刻的通过条件必须包含玩家对核心关系的理解；仅运行成功、画面类似或 AI 检查通过不能算体验已验证。
