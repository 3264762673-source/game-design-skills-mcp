# 像素物品美术：来源与案例

研究日期：2026-11-09。物品承担对象身份、用途类别与必要状态。I1 识别粒度、I3 交互线索范围经反例收窄；I2 世界/提示版本得到有限案例支持。

## 起源与工作定义

早期分辨率、色彩与硬件资源限制塑造了像素表达。S01 提供历史背景，S07 说明现代作品可以有意打破旧限制。本次不指定唯一发明者或起源年份。

工作定义是在最终观看尺度下控制像素与色块的连接、形状和信息职责；不限定固定尺寸、色数或生产管线。论文解释结构/抽象问题，未证明角色魅力、导航或游戏体验因果。

## 推导与独立检验

先观察 Shovel Knight（Yacht Club Games）与 Celeste（Maddy Makes Games）并读取作者工艺材料，将初版规则写盘，再打开 Stardew Valley（ConcernedApe）检查。三团队不等于统计独立实验；商店/官网选图存在宣传选择偏差。没有运行游戏或测玩家识别率。

实际观察：Shovel Knight screen_06/14/15/17/18/19；Celeste 官网 01/02/04；SLYNYRD 的 Character Sprite Process、Man Made Objects、Items 教学图。Shovel Knight 下载图高为 200px，只用于结构观察，不反推原资产尺寸。

检验图：Stardew Valley 的 [农场](https://www.stardewvalley.net/wp-content/uploads/2018/12/1_1screenshot15.png)、[夜市](https://www.stardewvalley.net/wp-content/uploads/2018/12/NightMarket-1-1.png)、[多人农场](https://www.stardewvalley.net/wp-content/uploads/2018/12/Multiplayer_Screenshot2-1.png)、[矿洞](https://www.stardewvalley.net/wp-content/uploads/2018/12/StardewValley_12-1.png)、[道路](https://www.stardewvalley.net/wp-content/uploads/2018/12/StardewValley_4.png)。图片仅用于核查，未随技能发布。

## 逐规则结果

| 规则 | 独立检验与修订 |
|---|---|
| I1 类别/形状 | **保留并限定粒度。**多人图菜叶、瓜形、工具和箱体能观察到形状差别；不能保证所有相邻作物种类仅凭剪影可分。粗类别先区别，精确种类允许名称等辅助信息。 |
| I2 世界尺度/投影 | **保留，增加例外。**图中举起的菜叶和左下物品名称提示可见；世界物与获取提示承担不同任务，允许不同展示大小。不能把真实物理比例当硬规范。 |
| I3 交互身份 | **收窄。**农场中的作物、箱子没有统一发光外圈；漂亮单帧也无法确定全部可交互对象。改为只对本任务中必要且容易误判的对象增加线索，其他对象允许通过约定、靠近反馈和操作学习确认。 |

## 复查与下一步

按同一任务、显示尺寸和内容比较修改前后。轮廓/灰度只是诊断视图，不能替代真实画面；静态图不能验证转向、遮挡行为、碰撞或状态因果。需要那些结论时，应取得目标项目的连续状态或引擎轨迹，再按规则卡检验。没有条目达到“本项目实测”。
