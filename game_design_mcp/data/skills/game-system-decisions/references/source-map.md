## 如何处理讲义中的张力

1. P113 把游戏空间表述为没有现实后果的安全空间，P153–P154 又要求讨论现实边界被打破的情况。本技能仅使用“约定改变对象意义”的分析价值，不承诺现实隔绝。
2. P115 对可量化终局的表述较强，P109/P118 同时承认定义的多样与局限。本技能把它作为目标导向游戏的工具，不据此否定沙盒、角色扮演或自由游玩。
3. P117 给的是理论关系。事件日志、最小修改、对照试玩、度量与撤回都是本次推导，不是讲义中已验证的实验结论。

采用两个独立维度，避免将“有理论依据”误认为“已实测”：

| 维度 | 标签 | 意义 |
|---|---|---|
| 依据 | 讲义转述 | 当前材料直接表达的概念，非已核验原书原文 |
| 依据 | 工程推导 | 根据概念提出的可操作检查、设计方案或指标 |
| 依据 | 项目观察 | 有记录的行为、日志或访谈；因果解释仍可能不确定 |
| 验证 | 待测 | 尚无该项目的效果数据 |
| 验证 | 初步支持／不支持／不确定 | 完成有限测试，报告条件、人数或次数及结果 |
